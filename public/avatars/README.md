# Avatars

The 24 pictures here are from the IP as Logo library at <https://visualskills.dev/ip-as-logo>,
which its page describes as "Free to download and use commercially." They were drawn with the
`ip-as-logo` skill (<https://github.com/s1dashu/ip-as-logo-skill>, MIT). Downloaded 2026-11-23 from
`cdn.ipaslogo.com/display-512/`, unchanged, and renamed to the animal each shows.

`src/lib/avatar.ts` lists them by name and gives each person one. A file added here is not used
until its name is added there.
